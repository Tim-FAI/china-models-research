# Китайские модели в роли агента: сравнение

Учебное исследование, 1 курс ФИИ МГУ.

**Вопрос:** как разные китайские модели справляются с одной и той же задачей в роли агента и сколько это стоит.

**Условия:** один harness (Claude Code + Free Claude Code), один ключ RouterAI, одна задача. Меняется только модель.

**Модели:** DeepSeek V4.1 Flash, Qwen, Kimi, GLM (уточняется).

**Что измеряем:** работает ли tool calling, токены, доля кэша, стоимость, время, качество результата, сколько раз пришлось поправлять агента.
