# Задание

Сделай интерактивный тренажёр для подготовки к коллоквиуму по командам Linux.

**Источник данных:** файл `spravochnik.md` в этой папке. Все команды, флаги и описания бери только из него. Ничего не выдумывай и не добавляй от себя.

**Результат:** один файл `quiz.html` в этой папке.

## Требования

1. **Один самодостаточный файл.** Весь CSS и JavaScript внутри `quiz.html`, без внешних библиотек, шрифтов и CDN. Файл открывается двойным щелчком в браузере без интернета.
2. **Полные данные.** Все команды из справочника (разделы 2–8) с описаниями и все их флаги с описаниями.
3. **Три типа вопросов:**
   - команда → что она делает;
   - флаг команды → что он значит;
   - описание → какая это команда.
4. **Четыре варианта ответа**, ровно один верный. Неверные варианты берутся из других команд или флагов справочника.
5. **Мгновенная проверка.** После ответа сразу видно, верно или нет, и показывается правильный ответ с пояснением.
6. **Настройка перед стартом:** выбор разделов и числа вопросов.
7. **Итоги:** процент правильных ответов и список ошибок.
8. **Прогресс** (на каких вопросах были ошибки) сохраняется в `localStorage`. Есть режим «повторить ошибки».
9. **Шпаргалка:** отдельная вкладка со всеми командами и флагами и поиском по ним.
10. **Оформление:** тёмная тема в стиле терминала, удобно пользоваться с телефона.

Когда закончишь, проверь код на ошибки доступными тебе средствами и кратко напиши, что сделано и что проверено.
