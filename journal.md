# Дневник: китайские модели в роли агента

## 21 ноября — проверка ключа

**Задача:** убедиться, что ключ работает, и отправить первый запрос к модели без harness.

**Что сделал я:** сохранил ключ в скрытую переменную (`read -s`), отправил запрос через `curl`.

**Проблемы:**
1. Терминал завис на `quote>`: при копировании потерялась закрывающая кавычка. Решение: Ctrl+C и команда в одну строку.
2. Ошибка `Invalid API Key`. Проверил длину ключа (35 символов) и начало (`sk-`): ключ целый. Причина: ключ выдан RouterAI, а я отправлял его на адрес ProxyAPI.

**Результат:** `deepseek/deepseek-v4.1-flash` ответила.
Вход 43 токена, выход 136 (из них 101 — рассуждения), кэш 0, стоимость 0.0103.
**Что понял:**
Свой ключ для своего сервера
